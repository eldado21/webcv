# webcv
My web CV

Made with angular

## How to run

1. Up the angular project:
```bash
npm install
npm start
```

## Build

```bash
npm run build
```

The output is written to `docs/browser`.

## Deployment

Every push to `main` is built and deployed to GitHub Pages by the workflow in `.github/workflows/deploy.yml`. Pull requests are only built and checked, not deployed.
